# Homebrew Tap

Homebrew releases for [tnl](https://github.com/tnldotdev/tnl), public URLs for localhost.

## Install

```sh
brew install tnldotdev/tap/tnl
```

The formula installs both the `tnl` client and the `tnld` daemon. It currently
tracks the latest release candidate, `v0.1.0-rc.5`.

## Upgrade

```sh
brew update
brew upgrade tnldotdev/tap/tnl
```

## Uninstall

```sh
brew uninstall tnl
```
